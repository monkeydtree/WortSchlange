## 🇨🇳 中文版本

### 简介
这是一个基于网页的德语单词学习游戏，将经典的贪吃蛇玩法与语言学习相结合。通过控制蛇吃掉正确的字母来拼写德语单词，在游戏中轻松学习德语词汇。

### ✨ 主要特性
- 🎯 **多难度等级**：支持 A1、A2、B1、B2、C 五个难度等级，适合不同水平的德语学习者
- 🎨 **像素风格界面**：经典黑白像素风格设计，简洁美观
- 📚 **双语释义**：每个单词提供中文和英文释义
- 🏆 **积分系统**：记录当前分数、单词进度和最高分
- 👤 **用户账户**：本地保存每个用户的游戏记录
- ⏸️ **游戏控制**：支持暂停、重新开始功能
- 📱 **响应式设计**：适配不同屏幕尺寸

### 🎮 游戏玩法
1. 使用方向键（↑↓←→）或 WASD 键控制蛇的移动
2. 游戏区域会随机出现字母，按顺序吃掉正确的字母来完成德语单词
3. 吃掉正确的字母：推进单词进度，获得分数
4. 吃掉错误的字母：蛇身会变长
5. 撞墙或撞到自己：游戏结束
6. 每完成一个单词得 1 分，分数越高游戏速度越快

### 📋 功能说明
- **难度选择**：在开始界面选择适合你水平的难度等级 A1（350词）A2（800词）B1（800词）B2（870词）C（570词）
- **单词显示**：实时显示当前单词、中文和英文释义
- **进度追踪**：显示当前分数、单词进度和最高分记录
- **用户登录**：首次输入用户名即可自动注册，数据保存在本地浏览器

### 🚀 快速开始
1. 克隆或下载本项目
2. 直接用浏览器打开 `Schlange.html` 文件
3. 无需安装任何依赖或服务器

### 📁 项目结构
.
├── Schlange.html # 主程序文件（包含 HTML、CSS、JavaScript）
└── README.md # 项目说明文档


### 🛠️ 技术栈
- **前端**：HTML5, CSS3, JavaScript (ES6+)
- **字体**：Press Start 2P (像素风格字体)
- **图标**：Font Awesome 6.4.0
- **存储**：LocalStorage (本地浏览器存储)

### 📝 注意事项
- 所有数据保存在浏览器本地，清除浏览器数据会丢失游戏记录

## 🇺🇸 English Version

### Introduction
A web-based German vocabulary learning game that combines the classic Snake gameplay with language learning. Control the snake to eat the correct letters and spell German words, making language learning fun and interactive.

### ✨ Key Features
- 🎯 **Multiple Difficulty Levels**：Support for A1, A2, B1, B2, C levels, suitable for learners at different German proficiency levels
- 🎨 **Pixel Art Style**：Classic black and white pixel art design, clean and aesthetic
- 📚 **Bilingual Definitions**：Each word provides both Chinese and English translations
- 🏆 **Scoring System**：Tracks current score, word progress, and high score
- 👤 **User Accounts**：Local storage of game records for each user
- ⏸️ **Game Controls**：Support for pause and restart functionality
- 📱 **Responsive Design**：Adapts to different screen sizes

### 🎮 How to Play
1. Use arrow keys (↑↓←→) or WASD keys to control the snake's movement
2. Letters will randomly appear in the game area; eat the correct letters in sequence to complete German words
3. Eat correct letters: Advance word progress and earn points
4. Eat wrong letters: The snake's body will grow longer
5. Hit walls or yourself: Game over
6. Complete a word to earn 1 point; higher scores make the game faster

### 📋 Features
- **Difficulty Selection**：Choose your proficiency level at the start screen A1（350 words）A2（800 words）B1（800 words）B2（870 words）C（570 words）
- **Word Display**：Real-time display of current word with Chinese and English translations
- **Progress Tracking**：Shows current score, word progress, and high score records
- **User Login**：Auto-registration by entering a username; data saved locally in browser

### 🚀 Quick Start
1. Clone or download this project
2. Open `Schlange.html` directly in your browser
3. No installation or server required

### 📁 Project Structure
.
├── Schlange.html # Main program file (contains HTML, CSS, JavaScript)
└── README.md # Project documentation


### 🛠️ Tech Stack
- **Frontend**：HTML5, CSS3, JavaScript (ES6+)
- **Font**：Press Start 2P (pixel art font)
- **Icons**：Font Awesome 6.4.0
- **Storage**：LocalStorage (local browser storage)

### 📝 Notes
- All data is saved locally in the browser; clearing browser data will result in loss of game records
- Word pool is embedded in the HTML file and can be customized as needed
- Recommended to use modern browsers (Chrome, Firefox, Edge, Safari) for best experience

## 🇩🇪 Deutsche Version

### Einführung
Ein webbasiertes Spiel zum Erlernen deutscher Vokabeln, das klassisches Schlangenspiel mit Sprachenlernen kombiniert. Steuern Sie die Schlange, um die richtigen Buchstaben zu fressen und deutsche Wörter zu buchstabieren, und machen Sie so das Sprachenlernen unterhaltsam und interaktiv.

### ✨ Hauptmerkmale
- 🎯 **Mehrere Schwierigkeitsgrade**：Unterstützung für A1, A2, B1, B2, C Niveaus, geeignet für Lernende mit unterschiedlichen Deutschkenntnissen
- 🎨 **Pixelkunst-Stil**：Klassisches Schwarz-Weiß-Pixel-Design, sauber und ästhetisch
- 📚 **Zweisprachige Definitionen**：Jedes Wort bietet sowohl chinesische als auch englische Übersetzungen
- 🏆 **Punktesystem**：Verfolgt aktuelle Punktzahl, Wortfortschritt und Höchstpunktzahl
- 👤 **Benutzerkonten**：Lokale Speicherung von Spielaufzeichnungen für jeden Benutzer
- ⏸️ **Spielsteuerung**：Unterstützung für Pause- und Neustart-Funktionalität
- 📱 **Responsive Design**：Passt sich verschiedenen Bildschirmgrößen an

### 🎮 Spielanleitung
1. Verwenden Sie die Pfeiltasten (↑↓←→) oder WASD-Tasten, um die Bewegung der Schlange zu steuern
2. Buchstaben erscheinen zufällig im Spielbereich; fressen Sie die richtigen Buchstaben der Reihe nach, um deutsche Wörter zu vervollständigen
3. Richtige Buchstaben fressen: Wortfortschritt vorantreiben und Punkte verdienen
4. Falsche Buchstaben fressen: Der Körper der Schlange wird länger
5. Wände berühren oder sich selbst berühren: Spielende
6. Ein Wort vervollständigen, um 1 Punkt zu verdienen; höhere Punktzahlen machen das Spiel schneller

### 📋 Funktionen
- **Schwierigkeitsauswahl**：Wählen Sie Ihr Sprachniveau am Startbildschirm A1（350 Wörter）A2（800 Wörter）B1（800 Wörter）B2（870 Wörter）C（570 Wörter）
- **Wortanzeige**：Echtzeit-Anzeige des aktuellen Wortes mit chinesischen und englischen Übersetzungen
- **Fortschrittsverfolgung**：Zeigt aktuelle Punktzahl, Wortfortschritt und Höchstpunktzahl-Aufzeichnungen
- **Benutzeranmeldung**：Automatische Registrierung durch Eingabe eines Benutzernamens; Daten werden lokal im Browser gespeichert

### 🚀 Schnellstart
1. Klonen oder laden Sie dieses Projekt herunter
2. Öffnen Sie `Schlange.html` direkt in Ihrem Browser
3. Keine Installation oder Server erforderlich
